# 1C MCP

Подключение **MCP (Model Context Protocol)** к **1С:Предприятие**, чтобы AI-агент
в VS Code видел конфигурацию, язык (BSL) и правила разработки 1С.

## Что внутри

- `docs/Архитектурный Манифест v1.0 MCP-интеграция 1С.md` — архитектурное решение
  с обоснованием выбора каждого компонента (Decision Log).
- `docs/План развёртывания MCP-1С (пилот).md` — пошаговый план развёртывания.
- `docs/research/` — база знаний: 92 источника, сравнительные таблицы решений,
  сводный индекс в `docs/research/INDEX.md`.

## Ядро решения

- Источник истины — автоматическая выгрузка конфигурации (`1cv8 /DumpConfigToFiles`) в git.
- MCP-сервер `1c-config` (Python, read-only) — метаданные и тексты модулей.
- BSL Language Server (MCP-режим) — язык и правила (диагностики стандарта).
- Агент: Cline / Roo Code (VS Code).
- Phase 2: live-доступ `mcp-1c` (feenlace) с аутентификацией, правила `ai_rules_1c`,
  токен-экономия `rlm-tools-bsl`.

## Лицензии и стоимость

Все компоненты бесплатны/open-source, кроме модели (DeepSeek API — по токенам) и
платформы 1С (лицензия уже есть). Подробности — в манифесте, §11.

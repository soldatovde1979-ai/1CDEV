- Идемпотентный PowerShell (lock/status/watermark/ротация логов), Go/No-Go,

- Таблица раскладки §5.2 и traceability-матрица (Приложение А).

## Замечания (по важности)

### 1. Синтаксис-справка платформы не закрыта BSL LS (риск — проверить)
§17 утверждает, что `global_member_info`/`type_info` «дают справку по платформе». Точно
так только для языка BSL и части библиотеки OneScript; полная библиотека функций
платформы 1С (`СтрНайти`, методы объектов метаданных и т.п.) живёт в `shcntx_ru.hbk`,
который BSL LS не индексирует. Приёмочный вопрос №9 («сигнатура `СтрНайти` через
`global_member_info`») может вернуть пусто. Действие: проверить на шаге 4.3; если пусто —
оставить синтакс-помощник (hbk) опцией Ф2 либо явно принять «точную справку даёт модель +
документация ИТС», не выдавая BSL LS за полноценный syntax-help.

### 2. feenlace/mcp-1c — теперь подтверждён
Проверил: MIT, 243★, последний push 2026-10-02, описание «one binary, 11 tools». Это не
[док], а факт — можно повысить в research/ и снять оговорку «не подтверждён research».
Выбор сервера для Ф2 «после проверки зрелости» оставляю в силе.

### 3. Java 17+, не «требует 21»
BSL LS официально: минимум 17, поддерживаются 17/21/23. Выбор JDK 21 безопасен
(закрывает оба варианта) — оставить, но поправить формулировки П2 и В-6.

### 4. Путь активации venv (мелочь)
Фаза 2.1: `. .venv/bin/activate` — unix-путь. На Windows без WSL —
`.venv\Scripts\Activate.ps1`. Уточнить среду разработки сервера.

### 5. `git rm -r -- src/cf` на ~100 тыс. файлов (оптимизация, не блокер)
`git rm -r` пофайловый и медленный; полная выгрузка — редкий путь (только после сбоя),
поэтому терпимо. Если будет долго — `rm -rf src/cf` + `git add -A` (или `git rm -r --cached`).

### 6. Один клиент Zoo/Roo (К9)
Для пилота на одного — согласен. При развёртывании на дирекцию (Ф3) вернуться к вопросу
единого `mcp.json` с `${env:ONEC_TOOLS}` и выбору Cline vs Roo.
